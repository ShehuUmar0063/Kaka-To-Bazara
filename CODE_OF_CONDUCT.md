# Contributor Covenant Code of Conduct

## Our Pledge
We pledge to make participation in our project a welcoming, respectful, and harassment-free experience for everyone—including farmers, agronomists, students, and developers—regardless of background, language, experience level, or identity.

## Expected Behavior
- Use welcoming, respectful, and constructive language.
- Focus on practical value for smallholder farmers and open-science collaboration.
- Respect differing viewpoints and agronomic local knowledge.

## Unacceptable Behavior
- Harassment, personal attacks, or discriminatory remarks.
- Publishing others' private information without consent.

## Enforcement
Project maintainers may remove or reject contributions or comments that violate this Code of Conduct. Issues can be reported via repository maintainers.
